# Orchestration battery — work-package specs

Internal build notes, not user documentation. These are the 13 per-work-package specs the
orchestration battery was built from, plus the shared contracts extract and the delegation notes.

They live in `research/` rather than `docs/` deliberately: everything under `docs/` is built into
the published documentation site, and these describe how the work was *dispatched* — they carry
agent-delegation mechanics and build-order constraints that mean nothing to a consumer of the
library.

The user-facing documentation for this battery is `docs/batteries/orchestration/`.
